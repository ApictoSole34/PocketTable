PocketTable is a platform for local multiplayer tabletop games.

Players use their Android devices as private game screens while the server manages the game state.

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Spring WebSocket
- Android (Java)
- Git

## Planned Games

- Poker
- Uno
- Makao
- Blackjack
- Mafia
- Custom Games

## Status

- [ ] Backend
